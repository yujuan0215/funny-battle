# 垂直切片：干擾決鬥已能對上的需求

對照課程第一章「團隊專題製作」垂直切片報告（[65]–[71]），以及它要回報的原型內容。範圍只看主選單的「干擾決鬥」：兩人自己打，玩家用延時道具改下一招的條件。

課程出處：<https://www.cmlab.csie.ntu.edu.tw/~kez/gp2026/decks/kG4jpQsGs8riXrZhTXCjlQ/#/d/ch01-introduction?p=95>

下面每一條都是現在這支 Godot 場景裡可以當場做出來的事。報告要交的投影片、問卷、網頁版、討論區連結不在這份清單裡。

## 已能玩、也能寫成使用者故事的部分

原型要求使用者故事寫成「我是誰，我可以驗證什麼」。干擾決鬥目前對得上的是：

- 我是玩家，我只使用鍵盤與滑鼠。`1` `2` `3` 選香蕉、彈簧、時停，點地面放下。`Tab` 可把單一招式拆開看，`R` 重看，`Esc` 回主選單。
- 我是玩家，道具不是點下去就生效。時停先亮圈，圈收起來時還站在裡面的人才定住。香蕉、彈簧要人走上去才作用。
- 我是玩家，不放道具時，兩人在近距離用普通攻擊。普通 1 打中且人還在範圍內才接普通 2，普通 2 打中才接普通 3，打完就停。
- 我是玩家，對方被時停定住時，距離決定遠程招。約 90 到 250 會站著開火，約 250 到 460 會原地蓄力。比 90 更近仍是普通攻擊，比 460 更遠兩邊都不放。
- 我是玩家，對方踩香蕉滑倒、人還在滑、距離約 140 到 400 時，另一人會追過去打。跑完仍夠不到就是打空。
- 我是玩家，朝對方跑且距離超過約 140 時踩到香蕉，會沿著跑的方向滑鏟。距離更近，或不是朝對方跑，則是滑倒。人如果站著踩，什麼都不會發生。
- 我是玩家，踩到彈簧才會被彈起。站著是小跳。跑著或正在出招是大拋。大拋到最高點才進入下落攻擊，下墜時水平距離約 70 以內才打中，否則是大拋落空。
- 我是玩家，場上同時最多四個道具。攻擊的距離、傷害、擊退、前後搖寫在 `docs/攻擊模組 - 攻擊模組.csv`，場景讀這張表，不是寫死在某一招裡。

這些對得上原型裡「現場可以玩、不要用投影片模擬」，也對得上垂直切片要能測試的那一條核心：玩家改的是條件，角色自己打出另一招。

## 已能對上的設計要求

原型要寫「在玩什麼、樂趣在哪」，以及至少一條設計支柱。干擾決鬥裡已經做在玩法上、只是還沒寫進報告的是：

- 核心體驗：兩人原本會自己對打。玩家不操作角色，而是預判走位，用延後生效的道具，讓一招原本不會出現的攻擊打出來。
- 可當作設計支柱的那一條：延時道具製造條件，不直接補傷害。香蕉對上滑倒或滑鏟，時停對上開火或蓄力，彈簧的大拋對上下落。
- 選擇對得上關卡要求的「玩家可以做的選擇，以及面對的挑戰」：選哪一種道具、放在誰的路上、放的時候人是在跑還是站著。放錯會落空，包括時停圈收起時人已經不在、追擊跑完打空、站著踩香蕉沒反應、時停時距離不對就不會蓄力。
- 同一套規則可以用 `Tab` 的拆解說明對回畫面上的結果，測試時不必先讀程式。

## 這份清單故意沒算進去的

中距離大約每三次會自己滑鏟一次。因此「完全不插手就只有普通攻擊」還不能當成已完成。滑鏟有兩種來源，測試者分不出是自己造成的還是角色自己出的。

史萊姆與火柴人先不出現在選角，也不進亂鬥。圖檔還在：`assets/chars/slime/body.png`、`assets/chars/stick/body.png`。四人亂鬥的第四人暫時用卸甲，原本是史萊姆。
