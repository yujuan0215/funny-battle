# FUNNY BATTLE · 小小反擊

2026-11-03 垂直切片展示版，以 `funny-battle-feat-player-feedback-and-boss-flow.zip` 為唯一基底。六章冒險都可進入、操作、通關、重試與結算；原始壓縮檔不變。

## 開始試玩

Mac：雙擊 `開始試玩.command`。它會尋找 Applications／Downloads 裡已安裝的 Godot。也可以用 **Godot 4.7** 匯入 `project.godot`，按 **F5**。第一次需等 Godot 匯入素材；整個遊戲離線可玩。

這份交付是完整 Godot 專案，啟動檔使用本機 Godot，未內附獨立的 Mac／Windows 執行引擎。

## 操作

- 滑鼠點選工具，或用 **1／2／3** 選畫面上由左至右的工具，再點場地部署。
- 主角自動移動及反擊；玩家決定道具的位置、時機。
- 每關開場及重試預設 **1×**。**Space 按住**進入 0.15×；右上角可切換 0.5×／1×。
- **Esc** 暫停／繼續、**R** 重試、**M** 音效開關。失去視窗焦點也會暫停。
- 道具有冷卻；香蕉、彈簧、時停可影響雙方。部署箭頭與接觸圈顯示真實方向和範圍。

## 六章的可玩內容

| 章 | 新判斷 | 工具 | 實際可用的解法 |
|---|---|---|---|
| 木棧前哨 | 單拳／衝撞預警 | 香蕉、彈簧 | 主角腳下放彈簧，落地開火；香蕉滑倒或誘導落橋 |
| 風車峽谷 | 重甲離地才受風吹 | 香蕉、彈簧 | BOSS 腳下放彈簧，風吹進亮起的側邊風車，每次扣 3 HP，需四次撞擊；拳腳與子彈無法破甲 |
| 鐘樓工坊 | 固定落點的三拍重錘 | 彈簧、時停 | 紅框鎖定後跳開，重錘落空造成核心反傷；時停延後重錘 |
| 冰封貨港 | 長距離滑行／撞停 | 彈簧、時停、沙袋 | 沙袋擋住一次地面衝撞並破甲；也能止住滑倒 |
| 熔爐車站 | 金屬箱與磁場 | 彈簧、沙袋、磁鐵 | 磁鐵放到鐵箱另一側，拉箱碰撞 BOSS；沙袋阻擋、彈簧反擊 |
| 王座機關塔 | 衝撞 → 重錘 → 終幕 | 彈簧、時停、磁鐵 | 三階段各 12 HP；階段間自動銜接、補給並記錄本次戰鬥檢查點 |

主角六關皆為 **6 HP**，血條寬 240，BOSS 血條寬 420；普通拳腳無法破甲。第 3–6 章彈簧射擊降為 2 傷害，機關仍造成 4／6 傷害。最終王換階段只補到至少 3 HP，保留弱者借力的定位。

每章開場只用兩行說明對手招式與場地特性，不直接揭露反制解法。

每章有安全開場、Boss 預警、實際扣血與回饋、勝敗原因、即時重試、返回地圖；勝利可直接進入下一章，第六章提供冒險結局。所有章節直接開放，適合報告自由展示。通關紀錄與試驗場分開。

第一、二章保留原版。第三至六章沿用原本自動行動、道具介入與 Boss 規則，增加實際可站立的凹谷、斜坡、階梯與側台；開場直接交戰，沒有新增 WASD 或進場長路。鏡頭依交戰高度調整。舊平地版移到「實驗關卡 → 舊版場地 · 3–6」，獨立保存紀錄；冰河與岩漿作為場景下方景觀，不新增落坑秒殺規則。

最終王重試從本次戰鬥已達成的階段開始；退出關卡後重新進入會從第一階段開始。章節通關紀錄會保存。

## 展示與驗證

完整解法、報告順序、驗收範圍與目前限制見 [垂直切片報告與試玩指南](docs/垂直切片報告與試玩指南.md)。`qa/` 保留實際遊戲擷取與測試輸出。

執行全部檢查（把路徑換成自己的 Godot）：

```sh
python3 tools/verify_demo.py /path/to/Godot
```

自動檢查涵蓋原有八套測試，另加入匯出道具與傷害檢查；最新結果請見 `qa/test-logs/results.json`。原有八套共 806 項，涵蓋原模式、香蕉／彈簧真實反擊、六章在 30／60／120 FPS 的實際通關、儲存、鍵盤配裝映射、暫停、階段檢查點，以及三種視窗比例的既有 UI 檢查。測試使用專案內隔離紀錄，不會改玩家進度。自動策略通關不等於新玩家盲測，也不是低階裝置效能保證。

保留原有角色、森林背景、繁體像素字體與授權。第二至六章背景以第一章為風格參考，由內建 imagegen 分別製作峽谷、鐘樓、冰港、熔爐與王座塔；可互動機關與 Boss 外掛裝甲由程式繪製，角色動畫仍共用原素材；定位為可報告的短篇可玩 Demo，未聲稱六套完成版專用角色美術。音效是本次原創合成，見 `assets/audio/CREDITS.md`。

舊有設計文件保留為歷史紀錄；尚未採用的完整遊戲構想（主線升降台、任選配裝、跨存檔階段檢查點等）不代表本版已實作。
