## 表單說明

感謝試玩《小小反擊》！請依照實際遊玩經驗填答，約需 2–3 分鐘。沒有標準答案，沒通關也歡迎回饋。本表不收集 Email，請勿填寫姓名、學號或其他個人資料。

## 題目

1. **遊玩測試回饋用匿名 ID**（簡答，必填）
   - 說明：請自訂一組代號，例如「小貓42」。請勿使用姓名、學號或 Email。
2. **你實際玩過哪些關卡？**（核取方塊，必填）
   - 第一關：木棧前哨
   - 第二關：風車峽谷
   - 第三關：鐘樓工坊
   - 第四關：冰封貨港
   - 第五關：熔爐車站
   - 第六關：王座機關塔
3. **這次大約遊玩多久？**（單選，必填）
   - 少於 3 分鐘／3–5 分鐘／6–10 分鐘／超過 10 分鐘
4. **我能理解如何選擇與放置道具。**（線性刻度 1–5，必填）
   - 1＝非常不同意；5＝非常同意
5. **我能看懂敵人即將攻擊的提示。**（線性刻度 1–5，必填）
   - 1＝非常不同意；5＝非常同意
6. **道具使用後的效果與受傷回饋清楚。**（線性刻度 1–5，必填）
   - 1＝非常不同意；5＝非常同意
7. **整體難度對你而言如何？**（線性刻度 1–5，必填）
   - 1＝太簡單；3＝剛好；5＝太難
8. **我有透過觀察、嘗試與調整策略取得進展的感覺。**（線性刻度 1–5，必填）
   - 1＝非常不同意；5＝非常同意
9. **我願意繼續挑戰其他關卡或再次遊玩。**（線性刻度 1–5，必填）
   - 1＝非常不同意；5＝非常同意
10. **哪個地方讓你困惑、卡住，或不知道為什麼失敗？**（段落，選填）
    - 說明：可註明關卡與當時做了什麼；沒有也可留白。
11. **有遇到錯誤或不順暢嗎？**（段落，選填）
    - 說明：請描述關卡、發生前的操作與看到的結果；若是效能問題，可補充作業系統與瀏覽器。請勿提供個人資料。
12. **最喜歡的部分，或最希望改進的一件事？**（段落，選填）

## 設定與繳交檢查

- 不收集電子郵件地址。
- 不限制每人只能填一次，避免強制登入。
- 不要求姓名、學號或檔案上傳。
- 不公開填答摘要，避免其他填答者看到匿名 ID 或文字回覆。
- 確認第一題為「遊玩測試回饋用匿名 ID」。
- 編輯者一般存取權：知道連結的任何人，角色為編輯者（依作業要求）。
- 作業繳交：Google Forms **編輯連結**。
- 討論區／邀請玩家測試：Google Forms **填答連結**。
- 不將可供任何人編輯的連結寫入公開 GitHub 文件；交到指定作業欄位即可。
