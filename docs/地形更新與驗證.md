# 地形更新與驗證

本次採用最後確認的範圍：**原版玩法，只增加地形起伏**。第一、二關保留；第三至六關原地改為起伏場地。開場仍直接交戰，沒有長距離行進段、部署後執行按鈕或新的 WASD 操作。

玩家繼續用 1／2／3 選工具、滑鼠部署、Space 按住慢速、R 重試、Esc 暫停、M 靜音。主角繼續自動移動與反擊，Boss 的招式、HP、原本機關傷害及第六關的階段檢查點沿用舊版。

地面輪廓參與站立、移動、彈簧落地和道具放置的計算。衝撞預警沿實際地面顯示；沙袋與鐵箱需與 Boss 位於同一高度才能命中，重錘記錄鎖定高度。鏡頭保留交戰全貌，依雙方所在高度平順調整，血條與工具列固定在畫面上。冰河與岩漿目前屬於景觀，不增加新的秒殺規則。

舊平地第 3–6 關位於 **實驗關卡 → 舊版場地 · 3–6**。保留原地形、數值與玩法，以獨立紀錄存檔，下一關與返回入口也留在舊版關卡內。

另外三個即時操作試煉留在實驗關卡，以各自開場顯示的按鍵操作，與主線分開。它們不代表主線改成直接控制角色。

## 驗證

`tools/verify_demo.py` 執行原有回歸檢查、獨立動作試煉，以及主線地形測試。主線第 3–6 關在 30／60／120 FPS 下使用原有道具策略實際通關，檢查直接開戰、原配裝和 HP、重新挑戰、暫停、攝影機取景、實際高度與跨層誤傷。第六關需走完三階段，沒有直接設定 Boss HP 來通關。

原版關卡的完整回歸測試改從保存的舊場地載入，與新場地的測試分開。測試檔及結果在 `tests/test_world_terrain.gd`、`tests/test_vertical_slice.gd` 與 `qa/test-logs/results.json`。所有測試使用隔離進度，不寫玩家存檔。實際渲染擷取在 `qa/world-3-arena.png` 至 `qa/world-6-arena.png`。

這些檢查證明流程、機關與地面判定可運作，不能證明已經好玩。原版可被頻繁切換道具與連點快速通關的問題仍需玩家盲測；依最新指示，本次沒有為了提高難度改寫主線核心玩法。
