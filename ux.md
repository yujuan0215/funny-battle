# Local player flow

Start → adventure map → first chapter → briefing → observe/deploy/counter → result/retry.

- Start, map and first chapter share the pixel forest visual target and square UI language.
- First chapter exposes banana and spring only, and includes one visible safety-rope rescue.
- Chapters 2–6 are inspectable blueprints with different environments and loadouts. They do not launch unfinished levels.
- The flask opens a separate test lab. Previous duel and spike challenge remain available there, with independent progress.
- Boss intent, direction, real-time countdown and recovery openings stay compact. Tool placement shows contact areas and nearby actors.
- Long explanations stay in the on-demand blueprint or design document. Basic controls and two-word tool labels remain readable.
