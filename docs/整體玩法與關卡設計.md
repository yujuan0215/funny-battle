# FUNNY BATTLE · 小小反擊

## 定位與目前狀態

單人、側視、像素風的「道具反擊」遊戲。玩家操作的是戰局：觀察 Boss，選擇道具和落點，讓弱小主角借力獲勝。核心樂趣是「我看懂了，所以這次成功」，不是看角色自行互打。

世界觀用一條線串起來：小修理工穿越失控的機關島，玩家是替他布置小機關的搭檔。每拆掉一座大型機關，就學會一種新的借力方式，最後面對控制全島的機關王。

這份文件區分三件事：第一章已有可玩的本地樣板；六章冒險與最終 Boss 是設計藍圖；原本的對打與尖刺挑戰留在獨立試驗場。尚未實作的章節可預覽構想，不能當成已完成關卡進入。

## 為什麼原本玩起來怪

| 問題 | 對玩家的影響 | 設計調整 |
|---|---|---|
| 主角自己輸出，Boss 很快連招 | 不放道具也在打，放了也不清楚差別 | 冒險首關主角平時防守，靠玩家製造滑倒、彈射等機會反擊 |
| 第一關一次有六種出招與落橋即死 | 還沒理解規則就失敗 | 首關固定單拳／衝撞，長預警、長收招，加一次安全繩 |
| 每關同樣三個道具、同樣空橋 | 策略變成亂放與等冷卻 | 每關一個場地規則、固定小配裝，逐章引入新道具 |
| 像素人物、海灘主選單、線框 HUD 混用 | 缺乏同一個世界的感覺 | 深色像素場景、暖色木石材質、方形介面與一致的圖示語言 |
| 只用更多血量增加難度 | 重複操作變久，沒有新的判斷 | 升級空間關係、行動組合與破綻，讓最後 Boss 考驗已學會的規則 |

## 一致的核心循環

**看起手 → 看場地 → 放一道具 → 看見連鎖效果 → 主角反擊 → 觀察下一招。**

- 主角自動移動與執行反擊，玩家控制道具、位置和時機。每場最多三種工具，不再同時要求玩家學動作操作。
- 預設半速；按住 Space 可再放慢。角色、道具壽命與冷卻同速，數字顯示實際秒數。
- Boss 起手先鎖定方向或落點，攻擊執行時不突然追蹤改向。紅色路線、形狀與倒數共同預警。
- 道具預覽顯示接觸範圍與目前在範圍內的人。雙方都會受影響，沒有靠文字猜的暗規則。
- 部署立刻確認；成功時串連「道具 → 狀態 → 命中」，反擊有短暫停頓、火花與實際扣血。
- 收招用綠色標示。傷害、破甲或落橋的結果必須可見；勝負最後有固定結算與立即重試。
- 每個場地都有安全的觀察空間，再讓玩家在同一規則下承擔風險。支線挑戰才縮短窗口或取消安全繩。

這個循環對應 MDA：規則是道具與位置；互動是誘導、位移與連鎖反擊；目標體驗是弱勝強、掌握規則與自己造成結果的成就感。是否好玩仍要靠新玩家實測，不以介面精美取代驗證。

## 道具語法

| 道具 | 一眼能理解的作用 | 要做的決定 | 不做什麼 |
|---|---|---|---|
| 香蕉 | 踩中後短距離滑倒 | 放在行進路線還是橋邊 | 不自動追敵或跨場地生效 |
| 彈簧 | 改變距離，落地後有反擊機會 | 救主角、改落點或引導敵人 | 不把「彈簧」改叫某一種動作 |
| 時停 | 範圍內暫停，換取蓄力時間 | 時停誰、在哪個起手節點 | 不直接造成大傷害 |
| 沙袋（規劃） | 止滑、製造停點，可擋一次地面衝擊 | 改變摩擦與行進終點 | 不成為永久無敵牆 |
| 磁鐵（規劃） | 拉動已標記的金屬物件 | 改箱子或軌道方向 | 不吸所有東西，材質要能辨識 |

原型試驗場仍保留遠端版本的「依放置位置決定彈簧方向」，用來比較操作可讀性；正式冒險首關先用較單純的拉開距離版本。後續要用盲測選出同一套冒險規則，再擴充到更多章節，避免同一工具在正式章節間暗中換規則。

## 六章冒險

每章只新增一個主要判斷；最多三種同時可用道具。下列章節 2–6 的背景圖是區分氣氛的像素方塊草圖，機關與 Boss 尚未實作。

| 章節／背景 | Boss 與可讀的行動 | 配裝 | 新學習與反勝畫面 |
|---|---|---|---|
| 1 木棧前哨：月夜森林、木棧橋 | 守橋鐵衛：單拳、直線衝撞 | 香蕉、彈簧 | 預警 → 部署 → 反擊；把追來的巨人滑下橋，或彈開後開火 |
| 2 風車峽谷：風車、藍色峽谷、布旗 | 風翼巡守：順風俯衝、逆風停頓 | 香蕉、彈簧 | 沿用已知工具，先學風向；順風彈射、逆風讓敵人停在陷阱 |
| 3 鐘樓工坊：銅齒輪、擺鐘、升降台 | 發條拳王：三拍蓄力、砸台 | 彈簧、時停 | 解鎖時停；在明確節拍中爭取蓄力，破壞關鍵發條 |
| 4 冰封貨港：雪、冰面、貨台 | 滑行裝甲蟹：長滑行、轉身慢 | 彈簧、時停、沙袋 | 解鎖沙袋；自己造止滑區，讓重甲衝過頭露出背部 |
| 5 熔爐車站：橘紅火光、軌道、鐵箱 | 熔爐機車長：沿軌衝撞、閘門重壓 | 彈簧、沙袋、磁鐵 | 解鎖磁鐵；把箱子送進路線，讓衝撞打開爐心 |
| 6 王座機關塔：靛色高塔、金色機關 | 百變機關王：三階段切換 | 彈簧固定＋四選二 | 綜合此前規則；用位置與場地，讓王親手打碎自己的核心 |

每關提供至少兩條可行反擊路線。道具是解法組合，不是「帶錯就完全無法獲勝」的鑰匙。章間可換裝，場內不突然要求一個玩家未帶的道具。

## 第一章的可玩樣板

- 主角 12 HP，Boss 12 HP。Boss 單次最多 1 傷害，沒有拳踢斬連段或針對滑倒／定住的追擊懲罰。
- 衝撞起手 1.4 遊戲秒，半速下約 2.8 秒；完整攻擊後收招 1.5 遊戲秒，半速約 3 秒。
- 彈簧成功開火 4 傷害，三次成功反擊可獲勝；香蕉也可創造普通連擊或地形勝利。
- 部署冷卻是試驗場的 70%，道具至少存留 4.5 遊戲秒。只顯示香蕉與彈簧，按 3 不會偷偷選到時停。
- 第一次落橋由安全繩拉回，不補血、不回復 Boss 血量；第二次落橋仍失敗。安全繩圖示用完消失。
- 自動策略驗證在 30／60／120 FPS 下，容許一次未命中部署及一次落橋救援，三次真實射擊都能獲勝。這證明存在易懂解法，不代表已完成玩家盲測。

## 最終 Boss：百變機關王

### 外形與共通規則

四倍於主角的發條裝甲玩具王：銅色肩甲、靛色披風、胸口一顆會按節拍發亮的齒輪心臟。危險來自動作輪廓與場地變化，不靠滿屏特效。三個可見的鎖扣表示進度，破一個就拆掉一組外甲或機關；不保留畫面上扣不完的最後 1 HP。

所有主要攻擊都有固定預警與天然收招窗口。彈簧是共通的位移／反擊解，其他配裝拓展替代解，不作唯一必需品。正式製作前須驗證「彈簧＋任意兩件」的六種配裝都能完成每一階段。

### 第一階段：衝撞鎧甲

肩甲亮起 → 鎖直線 → 衝撞 → 過頭停頓。玩家沿用第一章的香蕉／彈簧判斷，把攻擊導向兩側鎧甲鎖。沙袋可製造停點，磁鐵可送出鐵箱。兩次有效破綻拆掉護肩，攻擊範圍可見地縮小。

### 第二階段：發條心臟

胸口依序亮三拍 → 蓄力衝擊 → 核心打開。時停能延長蓄力反擊時間；磁鐵能把金屬箱送進炮口；沒帶這兩件也能用彈簧避開衝擊，在自然收招時開火。成功會拆掉發條，場地露出最後一條軌道。

### 第三階段：借力終幕

三處落點先依序點亮，最後一個才鎖定。王準備砸擊自己的核心所在區域；玩家用彈簧移走主角，或用已學過的箱子／摩擦操作改變引導位置。砸擊破核心，主角完成最後一擊。最後增加的是組合判斷，沒有突然新增的操作或隱藏弱點。

各階段完成後設檢查點與短暫換裝空間，失敗重來當前階段，避免把熟練前段變成重複勞動。首輪製作目標約 2–3 分鐘，這是目標時長，尚非已量測成品數據。

## 像素視覺與聲音

- 保留現有 64×64 角色與最近鄰取樣；整體用粗像素塊、深藍綠遠景、暖木銅材質，少量綠色表示機會、橘紅表示危險。
- 主選單、冒險地圖、首關背景共用森林視覺樣板，移除海灘混搭。場景細節壓低亮度，人物、工具與預警最清楚。
- UI 共用刻木銅扣九宮格、原創像素圖記與 Fusion Pixel 繁體像素字體，血條分段並保留損血拖尾；焦點、滑入、按下、禁用各有狀態。不把每段規則寫成常駐文字，道具名兩字、狀態兩到四字；完整構想放在章節預覽。選關改用地標與實際路線；規範及驗證見 `DESIGN.md`。
- 香蕉黃、彈簧橘、時停有辨識輪廓；形狀與標記補足顏色，避免只靠紅綠判斷。
- 警告、部署、彈射、命中、破甲、勝利各有短促可辨識音色；重擊保留低頻，工具用木／彈簧／鐘聲。後續配樂採簡潔旋律與 Boss 節拍，不讓每次部署都觸發大震動。
- 首關背景由內建 imagegen 生成並作為原型樣板。它還不是已鎖定精確調色盤的量產像素圖；來源與提示詞見 `assets/environments/art-direction.md`，其餘篇章是程式繪製的草圖。
- 現有放大人物暫作 Boss 佔位。成品需六種不同剪影：方肩鐵衛、長翼巡守、圓齒拳王、低伏裝甲蟹、扁車頭機車長、披風機關王，不靠把同一角色放大區別關卡。

## 製作與測試順序

1. 先測第一章：新玩家能否在 30 秒內說出自己在等什麼，兩次嘗試內主動完成一種反擊，並知道為何勝負。
2. 只做第二章風場原型，驗證同樣兩種工具是否真的產生新決策。未證明前不批量製作後四章。
3. 第三章驗證時停與蓄力；再逐一製作止滑、金屬物件，保持一章一個主要新規則。
4. 用五章現有機關拼出最終 Boss 灰盒，先跑完所有合法配裝與階段檢查點，再畫成品 Boss 與動畫。

保留條件：玩家能預測效果並有意重做成功操作。調整條件：只在解說後才懂、只能亂放、或拖慢速度仍看不出因果。不能用更多背景或解鎖數量掩蓋核心循環無趣。
